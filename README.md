A tiny deterministic Python program for the make.fun "The Robot Vacuum's Funniest Excuse" competition. It writes one original one-line excuse from a robot vacuum for missing a spot to `entry.txt`.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
cat out/entry.txt
```

## Determinism

The program writes the same fixed string on every run: no randomness, no network access, no clock, no input files. It runs twice and produces byte-identical output.

## Why this angle

The vacuum does not blame the dust, the rug, or a sensor — it confesses, then reframes the failure as self-interest. "Job security" turns a missed spot into a deliberate career move, and the punchline ("a spotless floor is how vacuums get retired") gives the machine a motive every worker recognises. It is an excuse, in the vacuum's own voice, from the vacuum's own world, landing in one line with no setup.
